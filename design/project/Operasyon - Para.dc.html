Tezgâh sözleşmesi (kodlayan ajan için)
  • Tek model → kasa/banka/Stripe aynı kavram; hesap yalnız bir filtre çipi. Ayrı ekran/ayrı mantık yok. Bakiye hareketlerden hesaplanır, elle yazılmaz.
  • Eşleştirme = öneri + onay → yeşil rozet güçlü aday (onayla), amber çoklu aday (seç), gri önerisiz (elle bağla). Otomatik kabul yok; import satırı silinmez, eşleşmesi değişir.
  • Mutabakat kuyruğu → sağ üstteki "eşleşmemiş satır" sayacı iş kuyruğudur; "her şey mutabık" hali iyi haber olarak gösterilir.
  • Sipariş tahsilatı elle girilmez → online/kapıda tahsilat kendi akışından düşer; elle giriş gider/transfer/sermaye içindir. Reklam giderinde kampanya etiketi zorunlu — Analitik'teki ROAS köprüsü budur.
  • İç terim yok → "MoneyMovement / reconciled / BankImportProfile" değil; "hareket · eşleşti/eşleşmedi · banka şablonu".
